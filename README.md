Campus Lost \& Found AI Matcher



An AI-powered web application that helps students find lost belongings and connect with people who have found them on campus.



Features



\- Student registration and login

\- Admin login

\- Report lost and found items

\- AI-powered item matching using TF-IDF and cosine similarity

\- Image similarity matching

\- Chat between users

\- Claim requests and item handover management

\- SQLite database



Technologies Used



\- Python

\- Flask

\- HTML, CSS and JavaScript

\- SQLite

\- TF-IDF and cosine similarity



How to Run Locally



1\. Clone this repository:

&#x20;  

&#x20;  "git clone YOUR\_REPOSITORY\_URL"



2\. Open the project folder.



3\. Install dependencies:

&#x20;  

&#x20;  "py -m pip install -r requirements.txt"



4\. Start the application:

&#x20;  

&#x20;  "py app.py"



5\. Open your browser and visit:

&#x20;  

&#x20;  "http://127.0.0.1:5000"
